# The Taste of Choice

A narrative taco-stand experience where every choice shapes the story.

## Overview

You run a small night market taco stand. Three customers visit your stand, and for each one you make choices about:
- **Communication Style** — How you greet them
- **Ingredients** — What you serve them
- **Presentation** — How you present their meal

Every choice creates a unique moment and reaction, shaping their experience.

## How to Run

1. Ensure `background.png` is in the same folder as `index.html`
2. Open `index.html` in a modern web browser
3. Click **"Start Your Taco Stand"** to begin

## Files

- `index.html` — Main HTML structure
- `styles.css` — All styling and tone system
- `script.js` — Game logic, customer data, and interactions
- `background.png` — Background image (user-provided)

## Features

- **Dynamic tone system**: Background gradient changes based on your choices
- **Typing effect**: Dialog text types out naturally
- **3 unique customers**: Each with distinct personalities and reactions
- **9 total choices**: 3 rounds per customer
- **Outcome summary**: See how your choices affected each person

## Technical Notes

- Pure vanilla HTML/CSS/JavaScript (no frameworks)
- Desktop-first responsive design
- Two-layer background system (gradient overlay + image)
- Optional audio support (graceful degradation)
- Smooth scene transitions and hover effects

## Browser Support

Works best in modern browsers (Chrome, Firefox, Safari, Edge).

## Deployment

This is a static site and can be deployed to:
- GitHub Pages
- Netlify
- Vercel
- Any static hosting service

Simply upload all files including `background.png` to your hosting platform.
